# 背景

我希望创建一个旅游计划构建与生成的项目。目前的创建旅行计划的痛点在于：
1. 我不知道在一次旅行中选择哪些景点，我需要自己搜寻目的地，目的地包括：景点、酒店、地铁站、火车站、飞机场、停车场、租车公司地址等等。
2. 当我选定一些目的地后，我不确定这些目的地之间的路程，我需要在确定目的地后，查询不同目的地之间的路程，这些路程决定了这个目的地是否能够被安排进一次舒服的行程中。
3. 根据目的地之间的路程不同，有时候我可能希望放弃一些目的地，还可能新增一些目的地。
4. 重复2~3步骤，直到获得一个满意的旅行计划。



# 目标

上述创建旅行计划的过程非常耗费精力，因此我需要一个能够高效创建旅行计划的工具。该工具运行在本机上。

# 功能要求

这个工具主体是一个基于高德地图开放API的应用。

## 收藏功能

支持收藏某个地址

## 创建旅行计划

创建旅行计划的步骤如下：
1. 输入起始日期与结束日期。
2. 按照天的粒度，对每天的行程逐个进行规划，具体流程见“单天旅行计划制定功能”。

## 单天旅行计划制定功能
### 待定目的地列表

1. 我可以将各种目的地加入待定列表，也可以删除待定列表中的目的地。
2. 我可以对待定列表中的目的添加备注，例如，标注这个目的地我需要完成拍照，备注需要允许上传图片。
3. 完成目的地的选择后，允许对目的地进行时间标记，例如什么时间到达某一目的地，游玩多久，什么时候离开。

### 路线规划

这个功能是为了能够让我快速决策这一天先去哪个景点，功能流程如下：
1. 初始情况下，路线规划为空。
2. 从不在路线规划中的待定目的地中，选择一个目的地，选定后代表我到达了这个目的地，将其标记为所在地，将该所在地加入当前路线规划。同时允许删除当前所在地，代表回退到上一个目的地，即上一个目的地成为所在地。
3. 在地图中，自动展示该所在地到所有未加入行程的目的地的交通方式、时间。
4. 重复2-3步，直到所有目的地进入路线规划。

### 暂存
将本日的旅行计划暂存，随后可以进行下一天的旅行计划制定。直到全部制定完毕。

## 保存旅行计划
将旅行计划命名并保存起来，后续可以随时查看、修改。
