LightRAG 是由香港大学数据智能实验室（HKUDS）开源的一种基于知识图谱的检索增强生成（RAG）框架。

与传统朴素 RAG 只做"文本切块 + 向量检索"不同，LightRAG 在索引阶段会调用大模型对文档进行实体与关系抽取，把文档内容组织成一张知识图谱，并为实体和关系分别生成向量索引与关键词索引。

在查询阶段，LightRAG 支持多种检索模式：
1. naive 模式：类似传统 RAG，直接基于文本块做向量相似度检索；
2. local 模式：围绕查询中的具体实体，检索其一跳邻居和相关的细粒度信息，适合回答具体、聚焦的问题；
3. global 模式：基于高层关键词和全局主题检索，适合回答"整体概览""主题总结"类的宏观问题；
4. hybrid 模式：同时结合 local 与 global 两路检索结果，兼顾细节与全局，是日常问答的推荐模式；
5. mix 模式：在 hybrid 基础上进一步引入向量块检索，召回更全面。

LightRAG 采用"增量更新"设计：新文档插入时只需对新增内容做实体抽取和图合并，不必重建整个索引，因此在文档频繁变化的场景下成本更低。
