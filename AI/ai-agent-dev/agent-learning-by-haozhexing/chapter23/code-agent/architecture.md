# 概述

本文为编程Agent的总体架构说明文档。

# 项目目标
我们要构建一个AI编程助手，他能够：
1. 阅读并理解当前工程代码，能够针对当前工程代码的问题给予解答。
2. 理解用户的任务要求、意图，并进行代码开发。
3. 生成、执行单元测试单元测试并根据测试结果判断下一步工作。


# 功能设计

## 阅读并理解工程

### 目标

1. 针对当前工程代码，能够解析并记录代码的结构、关系、功能。
2. 能够根据自然语言快速检索到相关联的代码片段。

### 解析代码

1. 遍历当前工程下所有文件，利用文件之间的引入关系、AST分析，以方法作为最小单元（对变量的读和写可以看作一个方法），构造方法之间的图。
2. 利用SSC收缩成为DAG得到凝聚图。
3. 从叶子节点开始解析，对每个方法利用代码本身的控制流、对外调用的方法，通过llm生成摘要，并记录至向量数据库。
4. 同时记录的静态信息，包括签名、关联、行数、返回值、hash等。


### 监听变化
1. 利用watchdog监听linux的文件变动，注册监听事件。
2. 采用定期+惰性方案，文件变动不立刻重新解析，而是进入待处理队列，触发重新解析的时候清空队列。

### 咨询代码问题

1. 解析人类语言，进行抽象与优化，从向量数据库中检索相关代码
2. 将相关代码与人类语言发送至llm，并给出答案。
