# 代码审查技能（code-based）

本技能的核心审查逻辑由 `tools.py` 中的代码实现（静态规则扫描），
你只需要调用工具并基于扫描结果撰写审查报告，**不要凭空编造扫描结果**。

## 工作流程

1. **获取代码**
   - 用户提供文件路径：先调用 `read_file(path=...)` 读取代码
   - 用户直接粘贴代码：跳过读取，直接进入第 2 步
2. **静态扫描**：调用 `analyze_code(code=...)`，获得结构化的扫描结果
3. **撰写报告**：基于扫描结果输出审查报告；对于扫描无法覆盖的语义问题
   （重复代码、命名规范、缓存与数据库查询优化等），由你阅读代码后补充判断

## 输出格式
使用以下格式输出审查结果：
- 🔴 严重：必须修复的安全或正确性问题
- 🟡 警告：建议改进的质量问题
- 🟢 建议：可选的优化建议
- ✅ 优点：值得肯定的良好实践
