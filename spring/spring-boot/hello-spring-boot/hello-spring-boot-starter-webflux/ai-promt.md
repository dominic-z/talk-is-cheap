

# 20260704 断点续传、断点下载功能demo

我需要一个能够实现大文件秒传、断点续传、断点下载的样例代码，你需要在当前项目中进行开发前端和后端代码。你只能在当前项目下操作文件。

当前项目是一个简单的webflux样例代码，所有代码都需要在webflux-app中，其中前端代码位于webflux-app模块的src/main/resources/my-static中。服务端代码位于webflux-app模块的src/main/java中。

关于前端代码，你应该：
1. 创建一个简单的页面，支持文件上传、文件下载功能
2. 不要使用如vue、reactor的开源框架，仅使用最基础的html/js/css。

关于后端代码，你应该：
1. 使用webflux作为网络容器，尽可能使用spring webflux提供的能力，如果需要引入新的第三方maven依赖，请与我确认后再变更。
2. 遵守先有代码的组织结构，例如在controller包中开发一个新的支持文件上传下载的Controller类，在service包中创建文件处理Service类，当然，你也可以创建其他的包，例如utils包存储一些公共工具类。
3. 关于文件存储，我不需要使用第三方存储功能，这只是一个demo程序，你可以将上传来的文件存储在本地路径，例如classpath中。
4. 虽然这只是一个demo程序，你需要考虑文件如果过大该怎么减少对系统压力的影响，例如使用webflux提供的异步、多路复用机制，减少线程消耗、cpu消耗。
